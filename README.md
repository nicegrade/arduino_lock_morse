
# 🔐 Электронный замок с обучаемой комбинацией (Arduino Nano)

**Неблокирующая архитектура · Код в EEPROM · Защита от подбора · Морзе-ввод**

## 📖 О проекте

Электронный кодовый замок на Arduino Nano, который открывается вводом последовательности **точек (.)** и **тире (-)** с помощью одной тактовой кнопки. Комбинация задаётся длительностью нажатий: короткое нажатие (< 500 мс) = точка, длинное (> 1000 мс) = тире.

Главная особенность — **полностью неблокирующая архитектура на millis()**: все таймеры (антидребезг, ввод кода, открытие замка, блокировка, мелодии, дыхание LED) работают параллельно без единого delay() в основном цикле.

Устройство поддерживает **мастер-режим** для смены кода (удержание кнопки 4 секунды при включении) и сохраняет комбинацию в EEPROM.

## ✨ Возможности

- ✅ Ввод комбинации морзе-стилем — короткие и длинные нажатия одной кнопкой
- ✅ Мастер-режим обучения — смена кода удержанием кнопки при старте
- ✅ Сохранение в EEPROM — код не теряется при отключении питания
- ✅ Защита от подбора — блокировка на 30 секунд после 3 ошибок подряд
- ✅ Антидребезг кнопки — 50 мс программная фильтрация
- ✅ Плавное дыхание LED — индикация ожидания через ШИМ
- ✅ Мелодичная звуковая индикация — приветствие, успех, ошибка, блокировка
- ✅ Визуальная индикация — 6 быстрых вспышек при успехе, 6 медленных при ошибке
- ✅ Неблокирующий код — ни одного delay() в основном цикле

## 🧰 Компоненты

| Компонент | Назначение | Примечание |
|---|---|---|
| Arduino Nano | Контроллер | ATmega328P |
| Тактовая кнопка | Ввод кода | D2, INPUT_PULLUP |
| Электромагнитный замок 12V | Исполнительное устройство | Через MOSFET P24NF10 (D3) |
| Светодиод 12V | Индикация | Через MOSFET P24NF10 (D5, ШИМ) |
| Пьезодинамик | Звуковая индикация | Через транзистор 2N5551 от 5V (D6) |

## 🔌 Схема подключения (пины)

| Пин Arduino | Компонент | Режим |
|---|---|---|
| **D2** | Кнопка | INPUT_PULLUP (LOW = нажата) |
| **D3** | Замок | OUTPUT (HIGH = открыть) |
| **D5** | Светодиод | OUTPUT (ШИМ) |
| **D6** | Пьезодинамик | OUTPUT (tone) |

> ⚠️ Замок и светодиод 12V подключаются через N-канальные MOSFET P24NF10 с общим минусом. Пьезодинамик — через биполярный транзистор 2N5551.

## 🚀 Быстрый старт

### 1. Установка

    git clone https://github.com/nicegrade/arduino_lock_morse.git
    cd arduino_lock_morse

### 2. Прошивка

1. Откройте `lock_morse/lock_morse.ino` в **Arduino IDE** (v1.8+ или v2.0+)
2. Выберите плату: **Tools → Board → Arduino Nano**
3. Выберите процессор: **Tools → Processor → ATmega328P или ATmega328P (Old Bootloader) **
4. Выберите порт и нажмите **Upload**

> Библиотеки не требуются — используется только встроенная `<EEPROM.h>`.

### 3. Использование

**Обычный режим (ввод кода):**

| Действие | Результат |
|---|---|
| Короткое нажатие (< 500 мс) | Точка (.) |
| Длинное нажатие (> 1000 мс) | Тире (-) |
| Пауза 2 секунды после ввода | Проверка комбинации |

**Код по умолчанию:** `. - .` (короткое — длинное — короткое)

**Мастер-режим (смена кода):**

1. Выключите питание
2. Зажмите кнопку и включите питание
3. Удерживайте 4 секунды до звукового сигнала
4. Введите новую комбинацию
5. Подождите 2 секунды — код сохранится в EEPROM

## ⚙️ Настройка

Все параметры вынесены в начало скетча:

    const unsigned long DEBOUNCE_DELAY = 50;        // Антидребезг
    const unsigned long SHORT_PRESS_MAX = 500;      // Макс. длительность точки
    const unsigned long LONG_PRESS_MIN = 1000;      // Мин. длительность тире
    const unsigned long PAUSE_TIMEOUT = 2000;       // Пауза до проверки кода
    const unsigned long OPEN_TIME = 800;            // Время открытия замка
    const unsigned long LOCKOUT_TIME = 30000;       // Блокировка (30 сек)
    const unsigned long MASTER_HOLD_TIME = 4000;    // Удержание для мастер-режима
    const int MAX_CODE_LEN = 12;                    // Макс. длина комбинации
    const int MAX_FAILED_ATTEMPTS = 3;              // Ошибок до блокировки

> 💡 **Совет:** для более быстрого ввода уменьшите LONG_PRESS_MIN до 700–800 мс.

## 🧠 Архитектура

    loop()
    ├── updateLed()          // дыхание / вспышки / моргание / мастер-режим
    ├── updateMelody()       // неблокирующее воспроизведение нот
    ├── lock timer           // закрытие замка по millis()
    ├── lockout check        // снятие блокировки по таймеру
    ├── readButtonWithDebounce()
    ├── обработка нажатий    // обучение / ввод кода
    ├── таймаут ввода        // проверка кода
    └── таймаут обучения     // сохранение и выход

**Ключевые решения:**

- Вместо delay(OPEN_TIME) используется lockCloseTime = millis() + OPEN_TIME с проверкой в цикле
- Мелодии проигрываются нота за нотой через updateMelody(), не блокируя ввод
- Вспышки LED управляются счётчиком шагов и millis()

## 🐛 FAQ

**Q: Кнопка не реагирует после включения?**
A: Проверьте, что при старте кнопка не нажата — иначе система может войти в мастер-режим.

**Q: Замок не открывается?**
A: Проверьте полярность MOSFET P24NF10 и наличие питания 12V. Пин D3 должен выдавать HIGH.

**Q: Как сбросить код, если забыл?**
A: Войдите в мастер-режим (удержание при включении) и задайте новую комбинацию.

**Q: Динамик хрипит / слишком громко?**
A: Добавьте последовательно с пьезоэлементом резистор 100–220 Ом.
